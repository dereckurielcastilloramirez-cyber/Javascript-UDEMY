PROMESAS Y PETICIONES

Metodos HTTP (resumen breve)

GET

Obtiene informacion del servidor. No modifica datos.

POST

Envia infromacion al servidor.

PUT

Actualiza un recurso existente.

DELETE

Elimina un recurso del servidor.

PATCH

Actualiza solo una parte de un recurso.

HEAD

Como GET, pero devuelve solo encabezados (sin cuerpo).

OPTIONS

Indica que metodos y opciones permite un endpoint.

TRACE / CONNECT

Metodos avanzados y poco usados en aplicaciones web comunes.

Codigos de respuesta HTTP

1xx: Informativo | 2xx: Exito | 3xx: Redireccion | 4xx: Error del cliente | 5xx: Error del servidor

200 OK

La solicitud fue exitosa y el servidor respondio correctamente.

201 Created

Se creo un recurso nuevo en el servidor.

204 No Content

La solicitud fue exitosa, pero no hay contenido para mostrar.

400 Bad Request

La peticion tiene datos invalidos o incompletos.

401 Unauthorized

Falta autenticacion o es invalida.

403 Forbidden

El servidor entendio la solicitud, pero no autoriza el acceso.

404 Not Found

El recurso solicitado no existe en esa ruta.

500 Internal Server Error

Ocurrio un error inesperado en el servidor.

503 Service Unavailable

El servicio no esta disponible temporalmente.
